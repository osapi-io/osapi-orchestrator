# Documentation

This directory holds the reference documentation for the orchestrator. The
programs that you can run are in [`examples/`](../examples).
[CONTRIBUTING.md](../CONTRIBUTING.md) tells contributors how to prepare a
workstation and which conventions to follow.

| Document                                     | Covers                                                        |
| -------------------------------------------- | ------------------------------------------------------------- |
| [features/README.md](features/README.md)     | The DSL, the DAG, guards, retry, discovery, and typed results |
| [operations/README.md](operations/README.md) | Each typed operation constructor, in groups by domain         |

The operation pages are in groups by domain: `agent`, `cmd`, `config`,
`containers`, `files`, `hardware`, `health`, `networking`, `node`, `security`,
`services`, and `software`.
